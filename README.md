# Named Pets

## A RuneScape 3 plugin
Custom names for all your pets & familiars with recolourable labels. Display in menus, dialogue & overhead!

Features:
* Names are visible in the hover menu & right-click menu, as well as any dialogue boxes & the Pets interface
* Show an ingame name label (toggle, recolourable)
